# Crime Stories Kotlin DSL

![Kotlin](https://img.shields.io/badge/Kotlin-DSL-7F52FF?logo=kotlin&logoColor=white)

A Kotlin DSL for writing interactive crime-investigation stories. Scenarios are expressed as readable Kotlin code and can model characters, clues, locations, and investigative actions.

## Project status

This is an experimental project. The `backend/` directory contains the Kotlin implementation and example scenarios. See its README for the backend-specific setup and run instructions.
